Coffee Shop Order Program

A program that simulates an ordering system for a wholesale coffee press company. Users input information about the company they are ordering for, before selecting the size, material, and quantity of coffee presses they want to order, along with 5 optional items they can include in the order. The program then calculates the line item based on the user's selections, before displaying the full order in the style of a receipt.

This program was built using these tools:

  • C# (for program logic)
  • Visual Studio 2022 (for program GUI)
